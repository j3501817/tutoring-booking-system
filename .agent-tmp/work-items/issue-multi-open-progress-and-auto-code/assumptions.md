# Assumptions — issue-multi-open-progress-and-auto-code

1. **進度切換支援同時多個開放進度（不會只有一個）**：
   - 原本切換目前開放進度時，會將其他所有進度強制設為 `IsCurrentProgress = false`（單選互斥）。
   - 現改為**每個進度可獨立切換「開放預約 / 關閉預約」**（Toggle `IsCurrentProgress`），開啟某個進度時**不會關閉其他已開放的進度**，同時已開放的進度也提供「關閉開放」按鈕可隨時單獨停用。
   - 新增每週進度勾選「立即設為目前開放進度」時，同樣僅將該筆新進度設為 `IsCurrentProgress = true`，不會把既有已開放的進度關閉。
   - 首頁（`Pages/Index.cshtml.cs`）顯示目前開放進度時，支援將多個開放中的進度主題串接呈現。

2. **進度代碼由系統自行建立且不需要顯示**：
   - 新增每週課程進度表單移除「進度代碼（如 W09）」輸入欄；後端建立進度時若未傳入 `code`，由系統自動依序產生唯一代碼（如 `W09`、`W10`...）寫入資料庫欄位以維持資料表相容性。
   - 所有介面（`Members` 學期與每週進度清單、`Parent` 家長預約與作業通知、`Teacher` 老師課堂與進度選單、首頁儀表板、操作成功提示訊息）均隱藏 `Code`，僅顯示進度主題名稱 `Title`。
