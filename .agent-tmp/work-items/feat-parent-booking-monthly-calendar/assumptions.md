# 假設與技術設計 (assumptions.md)

## 需求分析與設計決策
1. **先顯示月曆（Calendar View First）**：
   - 取代原本左側窄欄僅有 4 個日期小按鈕、右側一次展開所有時段的混亂排版。
   - 在家長「線上預約時段」頁籤首要位置呈現完整的「月份月曆 (Monthly Calendar)」，清楚列出該月份的每週每日格子（週日至週六）。
   - 預設月份：優先顯示有開放課堂之月份（例如：2026 年 10 月），並提供「上個月 / 下個月 / 返回本月」快速切換。

2. **在月曆中清楚標示「小組」與「團體」**：
   - 每個日期格中，若當天有時段：
     - **小組指導**：標示藍色/暖色小組標籤（例如：`小組 (2)`）。
     - **團體輔導**：標示綠色/灰色團體標籤（例如：`團體 (1)`）。
     - **已預約成功**：若孩子已預約該日的時段，加註綠色打勾徽章（例如：`✓已預約`）。
     - **額滿/剩餘空位**：提示可報名名額或是否額滿。
   - 若當天無課堂：顯示淺灰日期，不可點擊或點擊提示當日無課堂。

3. **點日期之後再出現當天課堂列表**：
   - 當家長點擊月曆上有課堂的某個日期時：
     - 月曆上該日期進入「選取高亮 (Selected Active)」狀態。
     - 月曆下方動態展示：**「📅 YYYY/MM/DD（週X）當日課堂列表（共 N 堂）」**。
     - 僅展示該選取日期的所有課堂時段卡片，具備五種目的下拉選單、預約按鈕、已預約狀態、改期/候補說明等完整操作。
   - 若尚未點選任何日期時：
     - 下方不堆疊顯示所有日期的冗長卡片，而是顯示清爽引導提示：
       「👉 請在上方月曆點選有標示課堂的日期，即可查看當日可預約時段」。
     - 亦可直接在網址帶入 `?date=2026-10-19`，此時自動選中該日並展開當天課堂。

4. **相容性與體驗**：
   - 同時支援純前端 JavaScript 即時篩選（點選切換無延遲、不重新加載整頁）與後端 `SelectedDate` URL 回退機制。
   - 保持「預約與改期規則」於月曆底部簡潔呈現。
