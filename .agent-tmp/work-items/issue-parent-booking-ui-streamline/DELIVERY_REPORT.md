# Delivery Report: issue-parent-booking-ui-streamline

## 變更摘要
1. **頂部資訊「三合一緊湊化」**：
   - 整合家長資訊、多子女切換下拉選單、可用總堂數（儲值堂數與贈送堂數膠囊）及 LINE 綁定狀態為單一緊湊控制條。
   - 消除原先分散佔據大半螢幕的 3 層卡片堆疊，大幅縮減垂直高度，讓月曆與時段第一時間進入可視區域。
2. **時段預約卡片「極簡列表化」**：
   - 移除百分比進度條與冗長說明文字。
   - 移除強制選擇「到班目的」的下拉選單，採用系統預設有效到班目的（後端提供安全 fallback），實現一鍵俐落預約。
   - 卡片轉為清爽的列表式 Row Card：時間、老師、類型、名額、立即預約/加入候補按鈕一目了然。
3. **月曆與時段互動「去冗餘化」**：
   - 移除未選日期時大面積的「請在上方月曆點選有標示課堂的日期」空佔位卡片。
   - 家長進入時未指定日期則預設自動選取今日或最近有課的一天，課堂列表自然展示。
4. **清理 30 分鐘手動候補確認橫幅**：
   - 徹底移除過時的「候補名額已釋出！系統保留 30 分鐘」橫幅，完全對齊「候補名額釋出後後台自動轉正扣堂並發送通知」的最新機制。
5. **資料庫 SQL**：
