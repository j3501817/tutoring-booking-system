# Assumptions: issue-parent-booking-ui-streamline

1. **頂部結構緊湊化 (Compact Header)**：
   - 將原本的標題卡片、多張大面積學生切換卡片、以及大面積堂數錢包卡片整合為高雅緊湊的一體式頂部面板。
   - 包含：學生切換下拉選單（或精巧切換標籤）、可用總堂數（清楚標註儲值堂數與贈送堂數）、LINE 通知狀態、週期預約按鈕。
   - 大幅縮減原本 3 層卡片佔據的垂直高度，讓月曆與時段第一時間進入可視區域。

2. **時段卡片極簡列表化 (Streamlined Slot Cards)**：
   - 移除繁複的百分比進度條、重複說明文字。
   - 移除「到班目的」下拉選單（後端若需要可預設為課後輔導或第一項有效目的，或直接免選快速預約）。
   - 保留核心關鍵資訊：時間、授權老師、課堂類型（小組指導／團體輔導）、剩餘名額狀態。
   - 預約與候補按鈕俐落清晰（立即預約／加入候補／已在預約名單）。

3. **月曆與時段互動去冗餘化**：
   - 移除未選日期時大面積的「請在上方月曆點選有標示課堂的日期」佔位提示框。
   - 若未手動點選特定日期，預設顯示今日或最近有課的時段，或在月曆下方以精緻收合條呈現。

4. **候補 30 分鐘確認橫幅清理**：
   - 徹底移除 `activeHolds` 與 30 分鐘手動確認橫幅代碼，與後台自動候補遞補轉正通知機制完全對齊。

5. **SQL 與資料庫變更**：
   - 本次純為前端 Razor View 佈局優化與精簡，不涉及任何資料庫綱要與 SQL 執行。
