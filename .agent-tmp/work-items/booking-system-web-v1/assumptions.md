# Assumptions & PM Confirmed Decisions (`booking-system-web-v1`)

## 1. PM 已核定決策 (2026-10-17)

1. **技術棧與執行環境**：
   - 採用規格書建議之 **C# ASP.NET Core + Razor Pages + Bootstrap 5 + Entity Framework Core**。
   - 本機開發與測試環境預設支援 SQLite / In-Memory 與 Azure SQL Connection String 切換，讓本機無須依賴外部 Azure SQL 即可完整執行與測試，部署至 Azure App Service 時直接透過環境變數切換為 Azure SQL 與 Azure Blob Storage。
2. **五種到班目的（可於後台設定調整）**：
   - 預設五種到班目的：`課業提問`、`作業輔導`、`考前複習`、`進度補課`、`錯題訂正`，並建立系統參數資料表供管理員維護。
3. **預約確認與扣堂時機**：
   - 家長於網站送出預約即正式成立並立即扣抵堂數（優先扣抵「贈送堂數」，不足再扣「付費堂數」），無須老師逐筆人工核准。
   - 滿額時家長可登記候補；當名額釋出時，系統發送 LINE 通知並保留 30 分鐘，家長於 30 分鐘內回網站點擊「確認轉正式預約」即成立並扣堂，逾時自動輪替下一順位。
   - 開課前 24 小時（含）以上取消預約，自動退還原扣抵類別之堂數並寫入沖正流水帳；未滿 24 小時取消則不退堂。
4. **儲值登錄與堂數更正權限**：
   - 儲值由**老師**獨立在後台登錄（含學生、儲值金額、堂數、匯款日期、帳號末五碼、備註與匯款憑證照片上傳）。
   - **老師与管理員**皆可透過「沖正／調整流水帳（Ledger Entry）」更正堂數或發放贈送堂數，所有異動皆為不可覆寫之 Append-Only 流水帳並記錄操作人與時間。

## 2. 補充實作假設（可隨時依 PM 回饋微調）

1. **登入與角色切換**：
   - 支援帳號／Email + 密碼登入（Cookie Authentication + Role Policy：`Parent`、`Teacher`、`Admin`）。
   - 為方便 PM 本機驗收所有角色與畫面，首頁／登入頁提供「快速切換測試角色（家長／老師／管理員）」的一鍵體驗登入按鈕（僅於開發/展示模式啟用）。
2. **預設課程與價格參數**：
   - 小組指導每進度限約 1 堂（扣 1 堂，預設每組 6 堂 NT$3,000，單堂計算基準 NT$500）；團體輔導不限堂數且免扣堂（0 堂）。
   - 每學期預設贈送 3 堂，插班生依剩餘天數比例四捨五入，學期結束由排程／管理員觸發贈送堂數歸零流水帳。
3. **附件儲存抽象化 (`IAttachmentStorageService`)**：
   - 定義儲存介面，本機預設儲存於受保護的私有目錄（不開放匿名靜態存取，需透過授權 Controller 檢視），正式環境可無縫掛載 Azure Blob Private Container。
4. **LINE 通知抽象化 (`ILineNotificationService`)**：
   - 僅發送通知（作業不佳通知、48 小時二次催促、候補釋出 30 分鐘保留通知），每一次推播均寫入 `LineNotificationLog` 紀錄表（含冪等鍵、狀態、重試次數），管理員與老師可於後台檢視推播紀錄與模擬發送。
