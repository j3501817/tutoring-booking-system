# 假設與架構考量 (assumptions.md)

## 1. 老師代學生預約「免扣堂數」功能
- **業務規則**：
  - 僅授權角色為 `Teacher` 或 `Admin`（或具備代理管理員權限）之使用者在代約時能啟用免扣堂數；家長自行線上預約時嚴格禁止傳入或啟用此選項。
  - 當啟用免扣堂數時，`creditsNeeded` 設為 0，不論學生剩餘堂數是否充足（甚至 0 堂）皆允許順利預約，且完全不異動學生的付費堂數或贈送堂數，亦不產生扣款流水帳 (`CreditLedgerEntry`)。
  - 後續若取消該筆免扣堂預約，因原本未扣除任何堂數，取消時亦不會向學生補退堂數。
- **UI 操作性**：
  - 提供兩種直覺操作：可直接點擊「不扣堂數代預約」綠色按鈕立即送出，或先勾選開關「選擇不扣堂數（特殊獎勵／專案代約）」後點擊「確認代預約」。

## 2. 作業追蹤與催促名單動態篩選
- **業務規則**：
  - 勾選作業不佳學生時，提供「學校」、「年別」、「班級」三級篩選下拉選單。
  - 學校連動班級：當選擇特定學校時，班級選單只列出所屬該學校之班級選項；若切換學校導致已選班級不匹配時，自動重置班級選項。
  - 學生選單依學校、年別、班級之篩選條件即時隱藏不符合之選項，若當前選取之學生被隱藏，則自動選取第一個可見學生，並在標籤即時更新「符合條件：X 位」。

## 3. 近期作業追蹤與預約解決狀態邏輯
- **標記追蹤**：老師在「作業追蹤與催促」填寫進度與說明並發送通知後，系統建立 `HomeworkWatchItem` 記錄，初始狀態為 `IsResolvedByBooking = false`（待家長預約）。
- **48 小時催促**：排程或手動點擊「執行 48 小時催促」會檢查超過 48 小時仍未預約者，將其標註 `IsSecondReminderFlagged = true` 並發送二次催促通知。
- **預約自動解決**：當學生完成預約（無論是家長自行線上預約，或老師代約），系統在 `CreateBookingAsync` 中會自動找出該學生尚未解決的作業不佳追蹤紀錄，一併更新為 `IsResolvedByBooking = true` 且紀錄 `ResolvedBookingId`，在頁面上即時顯示為綠色「已預約解決」。
