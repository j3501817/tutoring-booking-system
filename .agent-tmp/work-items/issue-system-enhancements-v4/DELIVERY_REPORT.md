## 交付變更項目

### 1. 學生/家長/老師管理
- **班別不連動學校**：徹底移除 `syncCascadingClasses` 動態置換邏輯，班別選項維持資優班、精英班，學校切換不影響班別。

### 2. 系統管理
- **拆分為兩個獨立子功能**：頂部設置「學期行事曆管理」與「系統欄位管理」切換分頁，空間獨立完整展示，不再混雜並排。
- **側邊欄次選單對應**：左側選單的系統管理展開為兩個清楚項目，可直接點擊進入對應子功能。
- **修復月曆標記**：修正月曆導覽列中遺留的 HTML 片段。

### 3. 家長預約與堂數（每日 00:00 排程自動過期歸 0）
- **自動過期排程**：新增 `SemesterBonusExpirationBackgroundService` 並註冊為 HostedService，每天台北時間 00:00 自動巡檢學期結束日期，一旦學期過期即自動將未用完之贈送堂數歸零，並寫入流水帳稽核。
