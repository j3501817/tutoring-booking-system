# 假定與決策紀錄 (Assumptions)

- **使用者決策**：
  1. 距離目前學期結束日 <= 14 天時，管理員後台最上方自動浮現黃色提醒框。
  2. 採用方案 A，使用名詞：本學期在學 / 未續報 / 續報 / 退班。
  3. 新學期生效時，全體在籍（本學期在學）學生自動補發新學期贈堂。
- **向下相容性**：
  - `IsDroppedOut` 維持同步連動（當狀態為 `DroppedOut` 時 `IsDroppedOut = true`，反之亦然），確保既有退班結算邏輯 100% 正常。
  - 新增 `StudentStatusLog` 資料表（`BK_StudentStatusLogs`），用以永久保存每一筆學籍變更歷史。
