# 規格與實作假設紀錄 (Assumptions)

1. **堂數卡片視覺整合**：
   - 原先 3 個獨立數字欄位（例如 2, 6, 8）容易被使用者誤算為 2 + 6 + 8 = 16 堂。
   - 整合為單一優雅卡片：主標題為「目前可用總堂數：8 堂」，副標題公式為「＝ 付費儲值 6 堂 ＋ 學期贈送 2 堂」，結構一目瞭然。

2. **已預約時段防護與標示**：
   - 學生若已成功預約該時段，卡片外框加上綠色高亮與「您已預約此時段」徽章，按鈕改為「已在預約名單」並提示如需改期至「我的預約與候補」頁籤操作。
   - 若同進度已預約其他小組指導時段，卡片提供改期導引。

3. **流水帳狀態與日期中文化**：
   - 表頭由「交易類型」更名為「狀態」。
   - `LedgerTransactionType` 枚舉轉為繁體中文：儲值入帳、學期贈送、手動贈送、預約扣堂、取消退堂、沖正調整、學期到期歸零、退班結算扣除。
   - 預約與點名狀態中文化：已預約、已取消、待點名、出席、遲到、請假、曠課。
   - 日期時間的星期由 `(Mon)` 改為 `(一)` 至 `(日)`。

4. **老師端時段管理與課堂點名**：
   - 時段排課與老師代預約改為按鈕啟動 Modal，釋放版面空間。
   - 時段清單支援 10 筆一頁分頁、修改（Modal）、刪除（二次確認並防護有學生預約時段不可任意刪除）。
   - 今日課堂點名優先呈現當天課堂時段，點擊時段切換上課學生名冊，提供單筆儲存與批次全選儲存，並於存檔期間啟用全螢幕 Overlay 遮罩鎖定畫面。

5. **資料庫結構**：
   - 本次調整完全復用既有 EF 實體與欄位，未異動 DB Schema，無需執行資料庫 migration 腳本。
