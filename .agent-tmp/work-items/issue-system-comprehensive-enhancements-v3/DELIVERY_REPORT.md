## 變更摘要
本分支完成了系統管理、家長預約、成員管理以及老師教務儲值頁面的 5 項綜合功能增強與體驗修復：
1. **系統管理**：
   - 支援多學期功能清單列表（含目前學期標籤、一鍵啟用切換、新增、編輯期間與刪除）。
   - 切換學期時自動觸發前學期贈送堂數歸零（流水帳記為 `BonusExpired`）。
   - 選項管理刪除與異動後，透過後端錨點與前端 `localStorage` 雙重機制，確保停留在同一個 Tab。
2. **家長預約與堂數**：
   - 月曆頂部「上月 / 本月 / 下月」按鈕群上下垂直置中。
   - 目前可用總堂數移除「=」等式，清楚呈現「付費儲值 X 堂」與「學期贈送 Y 堂（期限至當學期結束，以到班日計算，換學期歸 0）」。
3. **學生/家長/老師管理**：
   - 班別選項統一為「資優班」與「精英班」，不與學校連動。
   - 全面移除所有「（下拉選擇）」字眼。
   - 當學生關聯 2 位家長時，將兩位家長整合在同一個家庭群組卡片欄位內顯示，不再拆分為兩筆獨立紀錄。
4. **老師教務與儲值**：
   - 頂部原先的儲值登錄表單與沖正卡片全部替換為頂部工具列按鈕。
   - 修復 JS 語法缺失問題，確保點擊按鈕 100% 正常彈出 Modal 視窗。
   - 「近期儲值批次與匯款憑證紀錄」列表提升為主要畫面，並在上方加入學生學校、年別、班別（不連動）與匯款日篩選器。
5. **LINE 綁定防護**：
   - `LineAuthService` 與 `Login.cshtml.cs` 加強對未配置 Client ID 與連線異常的容錯，防止拋出 500。
