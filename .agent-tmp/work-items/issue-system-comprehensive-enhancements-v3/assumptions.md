# Assumptions & Design Decisions: 綜合功能增強與介面優化 v3

## 1. 系統管理 － 學期列表與多學期支援
- 既有系統只有單一學期設定，新增學期列表功能，列出所有學期（例如「115學年度第1學期（目前）」、「115學年度第2學期（下學期）」）。
- 支援新增學期（起訖日期、名稱），以及一鍵切換「設為目前學期」。
- 切換目前學期或結算學期時，自動將前學期的贈送堂數歸零（呼叫 `ExpireAllBonusCreditsForSemesterEndAsync`），符合「贈送堂數一換學期就歸0」之商業規則。

## 2. 系統管理 － 欄位管理 Tab 狀態保存
- 刪除或修改各 Tab（學校、年別、班別、到班目的、任教科目）時，後端重定向帶上對應的 fragment（如 `#tab-class`、`#tab-purpose` 等），前端亦配合 `localStorage` 與 `history.replaceState`，確保點擊刪除後頁面重整仍停留在當前 Tab。

## 3. 家長預約與堂數
- 月曆標題 `< 上月 本月 下月 >` 按鈕組加入垂直置中樣式（`align-items-center`、`my-auto`、行高對齊）。
- 可用總堂數卡片：移除 `=` 符號，改為清晰徽章呈現「付費 X 堂」、「學期贈送 Y 堂（期限至當學期結束，以到班日計算）」，下方說明「小組指導優先扣抵贈送堂數；贈送堂數一換學期即歸 0」。

## 4. 學生/家長/老師管理
- 移除所有輸入與選擇標籤上的「（下拉選擇）」字樣。
- 班別固定為「資優班」、「精英班」（或從資料庫中取得，不與學校連動）。
- 家長與學生關係列表改以家庭／學生為單元進行合併：若同一位學生關聯 2 位家長，家長欄位並列呈現 2 位家長的資料與操作按鈕，右側為學生卡片，不將該學生拆分為兩列。

## 5. 老師教務與儲值
- 頂部移除佔用大版面的表單卡片，改為「＋ 學生儲值登錄與憑證上傳」與「＋ 贈送／沖正堂數調整」兩個彈出視窗按鈕。
- 為按鈕配置原生 Bootstrap 5 屬性 `data-bs-toggle="modal"`、`data-bs-target`，並同時提供 JS 函式呼叫作為雙重防護，確保 100% 點擊必能彈出視窗。
- 列表提升為主要畫面，上方提供學生篩選（學校、年別、班別，無連動）與匯款日期篩選（支援日期匹配）。
