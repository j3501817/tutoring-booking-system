## 交付功能清單

### 1. LINE 官方帳號通知設定與授權綁定優化（解決附件一、二問題）
- **偵測 Messaging API 推播憑證**：系統現在會正確識別 `LineBot__ChannelAccessToken` 與 `LineBot__ChannelSecret`，頁面立即顯示綠色「LINE Messaging API 推播服務已連線就緒」標籤。
- **免跳轉直接綁定**：家長可直接輸入 LINE User ID（以 U 開頭 33 碼）一鍵綁定，系統自動向該 LINE 帳號發送驗證測試訊息，確認接收成功。
- **Channel ID 管理員線上配置**：若管理員需要啟用 LINE App 一鍵自動轉跳授權，可直接在頁面填入 Channel ID 儲存至系統設定，免去重新啟動 Azure Web App 的步驟。

### 2. 系統管理：學期與休假日改用「月曆」視覺化顯示（附件三）
- **學期行事曆月曆視圖**：
  - 支援前一月、後一月、本月切換，清楚標示學期進行期間。
  - 休假日格子以淡紅色背景與明顯徽章標示節日名稱（如「🏖️ 中秋節」），附帶一鍵移除休假按鈕。
  - 點擊空白日期格直接預設帶入該日期開啟「新增休假日」彈窗，排休更直覺。
- **下拉式選項改用 Tab 分頁**：
  - 學校、年別、班別、到班目的、任教科目改用乾淨的 Bootstrap Nav-Pills 分頁切換，告別雜亂擠壓的並排卡片。

### 3. 家長端預約月曆休假日全格反灰與原因彈窗（附件四）
- **全格深灰**：休假日格子套用專屬 `.calendar-month-cell.is-holiday`，整個格子反灰（`#e5e9f0`），邊框變灰，並標示「🏖️ 節日/休假原因」與「停課不開放」。
- **點擊彈窗**：點選休假日格子時觸發 `#modalHolidayNotice`，以專屬對話框顯示該休假原因，並說明停課與預約限制。
