# ⚡ Performance Checklist

本清單供 `REVIEW Gate` 與 `VERIFY Gate` 使用。若任務涉及資料查詢、背景作業、前端互動或外部 API，Reviewer 必須至少檢查下列項目。

## 1. 資料存取

- [ ] 查詢有明確範圍、分頁或上限，避免一次載入未限制資料。
- [ ] 沒有 N+1 query 或可預期會隨清單長度線性放大的重複外部呼叫。
- [ ] 熱路徑使用必要索引或既有快取策略；若無法確認，需在交付報告揭露。

## 2. API 與背景作業

- [ ] 外部 API 呼叫有 timeout、retry 上限與失敗處理。
- [ ] 大量處理工作不阻塞同步請求流程。
- [ ] 重試策略有退避機制，避免在服務異常時放大流量。

## 3. 前端與使用者體驗

- [ ] 初始畫面不載入不必要的大型資源。
- [ ] 清單、表格或圖表有合理的空狀態、載入狀態與資料量上限。
- [ ] 不因 hover、動態文字或載入狀態造成版面跳動。

## 4. 驗證紀錄

- [ ] 若有性能風險，`TEST_REPORT.md` 必須記錄測試方式、資料量假設與剩餘風險。
